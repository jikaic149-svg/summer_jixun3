# LCD 固件架构与运行契约

## 执行模型

当前目标为裸机协作式主循环，不包含 FreeRTOS Task：

1. `bsp_board_poll()`推进 HSE、PLL 和时钟切换状态机；
2. `ili9341_poll()`推进上电等待、软件复位和 Sleep Out；
3. XPT2046 每 5 ms 读取 5 组样本并做中值滤波；
4. UI 只在触摸事件或模型变化时重画对应控件；
5. CAN1 以轮询方式接收 QD4310 反馈；CAN初始化后自动请求双轴Enable，新应答确认后
   yaw/pitch各以10 ms周期运行位置PID；当前`GIMBAL_SCAN_ENABLED=0`，不进入往复Scan；
6. USART1/USART3中断在两个静态环形缓冲之间转发调试字节；
7. 循环末尾执行 `WFI`，由 SysTick或UART中断唤醒。

HSE、PLL 各有 100 ms 截止时间；LCD 初始化等待分别为 10 ms、10 ms、
120 ms，均通过回绕安全的时间比较推进。没有等待硬件标志的空转循环。
FSMC 连续像素写和软件 SPI 单字节传输是确定长度的同步操作，不等待外部事件。

## 静态内存

- 不调用 `malloc/calloc/realloc/free`；
- RGB565 字形缓冲为 16×16×2 = 512 B；
- 命令 FIFO 深度 8，所有槽静态分配；
- yaw诊断环形记录 256×44 = 11,264 B，保存最近约 2.56 s，停止时不清除；
- DAP/ESP调试桥使用两个256 B后备数组，各保留255 B有效容量，并保留24 B错误与
  丢弃计数；满载时丢弃新字节，不阻塞ISR；
- 不配置 320×240×2 = 153,600 B 的全帧缓冲；
- CCM 当前不放置变量，避免未来 DMA 可见性误用。

## 命令 Topic

| 字段 | 契约 |
|---|---|
| Topic | `app_command_t` 离散事件 FIFO |
| 生产者 | `target_ui_step()`和JX1接收适配，主循环上下文 |
| 消费者 | 双轴目标/启停分派或`control_port_submit()`，主循环上下文 |
| Payload | 命令枚举、`distance_cm`（厘米）、`angle_degrees`（带符号度）、`timestamp_ms`（uint32单调毫秒） |
| 深度 | 8 |
| 满载策略 | 立即返回 `APP_PUBLISH_FULL`，UI 显示队列已满 |
| 重试 | 无自动重试 |
| ISR | 不发布、不消费 |

当前弱 `control_port_submit()`是 UI 演示桩：所有非空命令立即返回
`CONTROL_SUBMIT_ACCEPTED`，不要求真实控制器接入，也不会驱动执行机构。这里的
“已接受”只表示 UI 命令链路完成。接入控制层时应提供强实现，并保持提交函数非阻塞；
需要异步完成结果时应新增有界状态 Topic，而不是让 UI 轮询控制器私有变量。

PB0发射和PB1充电继电器由独立BSP持有，两路均为高有效。主程序在应用初始化前将两路配置为
低速推挽输出并先写低，初始发射关、充电关。距离定位或固定靶只有在pitch目标成功提交后才跳转
发射控制页；自动搜索命令被接受后也跳转，失败时仍留在主界面。

`FIRE_DISTANCE`、`FIXED_TARGET`或`AUTO_SEARCH`成功提交后，组合层立即重置本轮充电累计、保持
PB0低并将PB1拉高；三个入口同时跳转既有发射控制页。`START`恢复为双轴Enable/Home命令，TFT
电机页也复用该语义，不再启动充电或搜索。主循环使用回绕安全的毫秒差值累计30 s，不忙等、
不占用定时器、DMA或IRQ。充电控制页仍发布既有
`CHARGE_START/CHARGE_ABORT`命令；断开命令将PB1拉低并保留累计值，开始命令在未完成的周期内
从暂停点恢复，只有再次成功提交三个任务入口之一，或已完成周期后的人工重新开始才清零。
自动搜索的120 s截止时间在暂停期间冻结，恢复时补偿暂停时长。

发射控制页发布既有`FIRE_PULSE/FIRE_ABORT`命令，`BACK`发布`CHARGE_ABORT`，并显示充电累计与
PB0脉冲倒计时。组合层只在30 s累计完成后接受击发；完成瞬间先写PB1低，随后距离定位、固定靶
和自动搜索都立即写PB0高，不再等待角度、视觉、TOF或稳定门控。PB0在500 ms后恢复低，期间
拒绝第二次发射。
任意路径都不允许PB0/PB1同时为高。取消自动任务、STOP或DISABLE会停止当前充电并保持两路低；
没有充满传感器、电压/电流保护或发射后自动恢复充电。
往复扫描不自动击发；距离定位和固定靶在30 s累计完成后自动击发一次。

`AUTO_SEARCH`由`Src/lcd_demo_app.c`内单一枚举状态机接管；当前
`AUTO_AIM_SINGLE_PASS_LOCK=1`的有效路径为`SEARCH -> SETTLE -> FIRING`，旧
`CALIBRATE_A/B/ALIGN`分支仍保留但不进入。yaw目标以8°/s在相对零点±50°内扫描；普通
`X_VALID`的每个新样本都作为相机视轴相对目标误差，以`-0.020°/px`、单步±2°和3°/s命令速度上限
累加到上一条Yaw命令目标；不把命令目标重置为电机反馈角。水平中轴进入±8 px后保持最后命令，
不继续到端点、不二次回扫，也不要求`X_FINAL/AIM_STABLE`；连续2个同方向样本越过±16 px才解锁。
随后用同一VIS样本的有效TOF距离，加25 cm得到靶心距离，
按`q=(37+25)/100=0.62`映射虚拟距离并求36.5 cm高弹道；超出可达包络时用49.26°最大射程角。
双轴误差≤1°用于进入稳定状态，但不作为30 s截止击发门控。
总截止时间120 s且充电暂停时间不计入；丢靶500 ms回到`SEARCH`但不延长运行中的截止时间。停止、Disable、人工断开发射、
轴故障和超时都进入`IDLE`并立即断开PB0。自动状态未结束时UI与命令分派均拒绝手动发射和其它
定位命令。本地发布`STOP/DISABLE/FIRE_ABORT`或TCP接收`STOP/DISABLE`时先同步取消自动状态并
断开PB0，再尝试进入有界命令FIFO；即使FIFO已满也不会延迟发射断开。主循环先执行
`gimbal_link_poll()`更新Latest Value，再分派命令，最后推进自动状态机，因此取消优先于同一轮的
自动击发判断；每轮最多消费一个新样本。

JX1维持显式ASCII字段、长度、序号和CRC；原命令枚举值不变，在尾部追加
`SET_YAW_TARGET/SET_PITCH_TARGET`。命令`value`按`int16_t`解析，两个手动目标命令在进入FIFO前
均检查±50°；发布和ACK均非阻塞，不自动重试。

视觉/TOF使用独立`VIS`状态帧，不进入离散命令FIFO。MaixCAM2是生产者，STM32主循环是
消费者；payload为`x:int16像素`、`d:uint16毫米`、`f:uint8有效位`和`w:uint16像素`。
接收端使用单槽Latest Value并在每个完整帧后立即取走；CRC、长度、字段范围或flags语义
不一致时整帧丢弃并增加协议错误计数。flags的bit3为`AIM_STABLE`，且接收端强制它必须同时
具有`X_FINAL|X_VALID`。MaixCAM2按`frame`去重，只有3个不同的新`X_FINAL`样本连续位于中心
±8 px才置该位，任一无效、非最终或越界样本立即清零。500 ms没有新帧即失效，UI显示`-- cm`；
不重发，也不从无效值推断有效性。VIS帧本身不会启动自动事务，只有用户先发布`START`或`AUTO_SEARCH`
后状态机才消费它进行角度调整和受限单次击发。用户点击`FIRE_DISTANCE`或`FIXED_TARGET`时，
固定靶只使用500 ms内同帧有效且原始值位于500～1000 mm的TOF箱体前沿距离，增加250 mm后
显示靶心距离，并按上述0.62高弹道实测映射设置Pitch；无新帧、距离无效、超时或越界时保持原
目标并返回距离提示。“距离定位”单独使用UI/JX1保存的50～100 cm人工距离，按地面0 cm低
弹道设置Pitch，不消费VIS距离。

当前开发热点中MaixCam2为TCP服务端`192.168.215.66:9000`，ESP8266为客户端；
端点由`Inc/lcd_demo_config.h`统一配置，连接失败后仍按原3 s周期进行有界重连。

## DAP与ESP8266调试桥

- USART1使用PA9/PA10、AF7、APB2=84 MHz、115200 8N1，连接板载DAP虚拟串口；
- USART3使用PB10/PB11、AF7、APB1=42 MHz、115200 8N1，经跳帽连接ESP8266；
- USART1接收字节进入PC到ESP有界环，USART3接收字节进入ESP到PC有界环；发送端
  仅在队列非空时启用TXE中断；错误和满载有独立计数，不自动重发；
- 该桥是联调端口，不是业务Topic，也不解析AT或TCP帧。正式通信接入后由Device层
  状态机替换透明桥，应用层不得消费原始UART字节。

## UI 刷新

UI 使用固定控件表和 64 位 dirty mask。按下、释放、反馈、状态、视觉距离、方位角和仰角分别
使对应控件失效；页面切换才整屏重绘。矩形采用半开区间 `(x,y,width,height)`，
ILI9341 窗口末端只在 Device 层转换为 `x+width-1/y+height-1`。

## QD4310 启停与双轴角度保持

- 当前临时配置`GIMBAL_SCAN_ENABLED=0`；TFT的Scan入口变灰，本地`SWEEP`
  不发布，TCP `SWEEP`返回`INVALID`；双轴固定目标保持不依赖该开关；
- BSP 使用 PB8/PB9 的 CAN1，APB1=42 MHz，位速率 1 Mbit/s；不使用中断或 DMA；
- Device 的 Enable/Disable 均发送标准帧 `0x400+ID`、DLC=3，数据分别为
  `01 00 00`/`02 00 00`；当前 yaw/pitch ID
  分别为 `0x00/0x01`，编译期禁止重复 ID；
- 只接受 `0x500+ID`、DLC 至少 8 的应答，byte0 bit0 表示使能状态；
- 两个事务各自只有确认、拒绝、250 ms 超时和 CAN 排队失败出口；只有两轴都确认
  目标 enabled bit 才显示 `YAW/PITCH OK` 或 `YAW/PITCH OFF`；
- CAN初始化成功后自动请求双轴Enable；人工`ENABLE / HOME`复用同一有界事务。请求前记录
  两轴响应计数基线；两轴均确认Enable且响应计数均越过本次基线后，以当前yaw编码器值
  建立yaw相对0°，pitch固定使用实测`0xEE77`作为水平0°；
- Enable完成后立即启动两个100 Hz位置环，默认目标均为0°。主界面可将yaw目标设为
  ±50°、pitch目标设为±50°；人工离散改目标会清零对应积分项，下一控制周期开始追踪；自动搜索的
  连续斜坡和视觉增量目标不清零Yaw积分；
- yaw位置PID直接输出`0x03`电流：
  `Kp=0.080 A/°、Ki=0.002 A/(°·s)、Kd=0.006 A/rpm`，误差限幅 8°，
  积分限幅 0.010 A，总电流限幅 0.70 A；不使用角速度串级或编码器差分估速；
- pitch使用独立的100 Hz位置PID追踪可设置目标，当前参数为
  `Kp=0.010 A/°、Ki=0.0002 A/(°·s)、Kd=0.0005 A/rpm`，死区0.20°、积分区1.0°，
  电流限幅0.30 A、相对水平零点硬边界±90°；手动pitch目标范围±50°，距离定位内部
  目标上限±85°；
- yaw超过±55°、pitch超过±90°、任一轴反馈超时或发送失败时停止双轴控制并
  尝试向两轴各发一次0 A，但保持 Enable；`ZERO CURRENT`停止双轴PID、分别发送0 A并
  保持 Enable，只有用户点击`DISABLE`才发送双轴 Disable；
- CAN 配置为单次发送，断线时不会无限自动重发；
- 本测试状态直接映射到 UI 状态和底部提示，不进入 `app_command_t` 命令 FIFO。

## 触摸事件

- PENIRQ 低有效，当前轮询，不在 ISR 中读软件 SPI；
- 连续 3 次有效样本才产生 Press，连续 3 次无触摸才产生 Release；
- Click 要求按下和释放命中同一控件；
- 手工距离输入只在50～100 cm时发布，保留用于UI和JX1兼容，但三种任务不消费该值；
- 有效`VIS` TOF原始距离视为箱体前沿，固定靶/自动搜索要求50～100 cm，加250 mm显示靶心距离；
  距离定位使用人工设定50～100 cm和地面0 cm低弹道，不消费VIS；
- 固定靶和自动搜索按36.5 cm靶心、`q=0.62`实测高弹道距离映射设置Pitch；距离定位使用未套用该映射的地面0 cm低弹道。距离定位和固定靶
  成功定位后立即启动充电，30 s累计完成后自动发射；JX1的`FIRE_DISTANCE`携带当前人工距离；
- “距离定位”“固定靶”成功完成目标提交或“自动搜索”命令被接受后才进入发射控制页；
  页面内“发射”按钮产生500 ms一次性脉冲，“立即断开发射”可提前结束脉冲，`BACK`暂停充电。
  手动发射必须先完成30 s累计充电；充电页保持既有布局，支持断开暂停和继续累计；
- 点击主界面YAW/PITCH卡片进入共用带符号数字键盘；YAW和PITCH均只接受±50°，
  `+/-`切换符号，确认前不修改实际控制目标，取消直接返回；
- `ENABLE / HOME`重新使能双轴、建立yaw零点并启动双轴目标保持；当前`SCAN OFF`不发布
  往复扫描命令；`ZERO CURRENT`停止两个PID、向两轴发送0 A并保持双轴Enable；
  `DISABLE`发送双轴Disable；
- MCU复位后自动发送新的Enable事务；等待应答期间UI显示`ENABLING`，不使用旧状态；
- 上述按钮都是普通软件命令，不声明为硬件急停或安全互锁。
