# STM32F407VE LCD 与触摸硬件映射

信息来源：`STM32F407VE_开发板_原理图_v5.5.pdf`、
`显示屏_2.8寸_原理图.pdf`（均为单页原理图）与资料包中的
`01--STM32F407_显示屏示例_未移植LVGL`。目标 MCU 为
STM32F407VET6、LQFP100，外部晶振 25 MHz。

## 时钟与存储

| 项目 | 配置 |
|---|---|
| SYSCLK/HCLK | 168 MHz，HSE=25 MHz，PLLM=25、PLLN=336、PLLP=2 |
| APB1/APB2 | 42 MHz / 84 MHz |
| PLLQ | 7，得到 48 MHz（为后续 USB 保留正确时钟） |
| Flash | 512 KiB，`0x08000000..0x0807FFFF` |
| SRAM | 128 KiB，`0x20000000..0x2001FFFF` |
| CCM | 64 KiB，当前不使用；外设/DMA 无法访问 |

时钟启动采用有限超时状态机：HSE 和 PLL 各 100 ms，失败后进入明确错误状态，
不切换到未经验证的替代时钟继续驱动 LCD。

## P5 34 针 LCD 接口

| P5 | 信号 | MCU/说明 |
|---:|---|---|
| 1 | NE1 / CS | PD7, FSMC_NE1 |
| 2 | RS | PD11, FSMC_A16 |
| 3 | NWE / WR | PD5, FSMC_NWE |
| 4 | NOE / RD | PD4, FSMC_NOE |
| 5 | RESET | 板级 NRST，不能由 LCD 驱动独立控制 |
| 6..9 | D0..D3 | PD14、PD15、PD0、PD1 |
| 10..18 | D4..D12 | PE7..PE15 |
| 19..21 | D13..D15 | PD8、PD9、PD10 |
| 22 | GND | 地 |
| 23 | LCD_BL | PA15，高有效；占用 JTDI，仅保留 SWD |
| 24、25 | 3.3V_LCD | LCD 电源 |
| 26、27 | GND | 地 |
| 28 | NC | 连接器符号写有 5V，但主板侧明确未连接 |
| 29 | T_MISO | PE3，软件 SPI 输入 |
| 30 | T_MOSI | PE2，软件 SPI 输出 |
| 31 | T_PEN | PE4，低有效，轮询方式 |
| 32 | NC | `MO` 未连接 |
| 33 | T_CS | PD13，低有效 |
| 34 | T_SCK | PE0，空闲低电平 |

LCD 使用 FSMC Bank1/NE1、16 位异步 SRAM Mode A。外部 A16 在 16 位总线下
对应 CPU 字节地址 A17，因此命令地址为 `0x60000000`，数据地址为
`0x60020000`。首版时序为：读 ADDSET=15/DATAST=60，写
ADDSET=3/DATAST=8；需在实机上用逻辑分析仪确认后才能继续收紧。

## 屏幕与触摸约定

- 显示控制器：ILI9341，RGB565，横屏 320×240，MADCTL=`0xA8`。
- 触摸控制器：XPT2046，GPIO 软件 SPI，命令 `0x90/0xD0`，5 点中值采样。
  软件时钟半周期至少约 1 us；每次转换显式丢弃 BUSY/null 拍、高低电平
  各等待至少 5 us，再只读取 12 位；初始化先完成一次 `PD1:PD0=00`
  转换以启用低有效 PENIRQ。精确波形仍以逻辑分析仪测量为准。
- 屏模块原理图确认 PENIRQ 依赖芯片内部约 50 kΩ 上拉，板上无外部上拉；
  T_CS 由 10 kΩ 上拉。触摸 SPI 与预留 W25Q128 共线，但片选独立。
- 按下和释放分别要求连续 3 个有效样本；采样周期 5 ms。
- 坐标范围严格为 `x=0..319`、`y=0..239`。
- 编译期默认标定来自板厂横屏系数，并修正其漏写的 X 轴负号。不同屏必须实测
  四角原始值，然后修改 `Inc/lcd_demo_config.h` 中的四个 `TOUCH_RAW_*`。
- P5 未引出 TE，无法做硬件撕裂同步；界面使用控件级脏区刷新。

## CAN1 与 QD4310

开发板 v5.5 原理图确认，板载 TJA1050 通过跳帽接到 PB8/PB9，而不是旧工程中
使用的 PD0/PD1。当前配置如下：

| 项目 | 配置 |
|---|---|
| CAN1_RX / CAN1_TX | PB8 / PB9，AF9 |
| 收发器 | 板载 TJA1050，使用前需接通 PB8/PB9 跳帽 |
| 位速率 | 1 Mbit/s，APB1=42 MHz，Prescaler=6、BS1=5 TQ、BS2=1 TQ |
| QD4310 yaw | ID `0x00`；Enable=`0x400: 01 00 00`；Current=`0x400: 03 LL HH`；应答=`0x500` |
| QD4310 pitch | ID `0x01`；Enable=`0x401: 01 00 00`；Current=`0x401: 03 LL HH`；应答=`0x501` |
| pitch水平零点 | 用户确认约+6°时炮体水平；现场原始编码器=`0xEE77`，相对旧零点实测约+5.68° |
| 角度与目标 | 16位编码器回绕差值换算为度；yaw上电当前位置为0°、目标±50°；pitch以`0xEE77`为0°、手动目标±50°；距离定位使用人工距离/地面0 cm低弹道，固定靶和自动搜索使用箱体前沿+25 cm、36.5 cm靶心及0.62实测高弹道映射；内部目标上限±85° |
| 电流极性/限幅 | yaw `+1`、0.70 A；pitch `+1`、0.30 A。pitch极性尚未完成闭环实机确认 |

PD0/PD1 已作为 FSMC D2/D3 使用，不能再切换为 CAN1；选择 PB8/PB9 后可与并口
LCD 同时工作。QD4310 与开发板必须共地，CANH/CANL 不得反接，总线两端应有
120 Ω 终端。实机已确认两轴命令均有 ACK，CAN ESR=0。
用户最终确认 yaw 为 ID `000`、pitch 为 ID `001`，可在同一总线上区分双轴。

## 发射与充电继电器

开发板 v5.5 原理图将 PB0、PB1 均标为完全空置，且两者在 P2 双排针的同一横排，
当前工程没有其它复用冲突：

| 信号 | MCU/排针 | GPIO 配置 | 有效电平与上电状态 |
|---|---|---|---|
| 发射继电器 | PB0 / P2-11 | 推挽输出、低速、下拉 | 高有效；初始化先写低，默认断开 |
| 充电继电器 | PB1 / P2-42 | 推挽输出、低速、下拉 | 高有效；初始化先写低，默认断开 |

`bsp_cannon_relay_init()`在主程序最前段完成初始化，不使用定时器、DMA或中断。
距离定位、固定靶或自动搜索成功提交时保持PB0低并将PB1拉高，主循环累计30 s后先恢复PB1低，
随后立即输出一次PB0高电平500 ms，不等待角度、视觉、TOF或稳定条件。手动发射也必须先完成
本轮30 s累计充电。发射页和充电页的`BACK`、人工断开、
STOP或DISABLE将PB1拉低并保留累计时间，再次开始从暂停点继续。再次提交三个任务入口之一才
强制清零并重新计时；`START`只负责双轴Enable/Home。任何路径都禁止PB0/PB1同时为高。当前没有
充满反馈、电压或电流保护，30 s仅是软件定时。
复位阶段GPIO仍为
高阻输入；高有效PB0/PB1均应外接约10 kΩ下拉，保证复位阶段继电器关断。初始化完成后两路仍
保持低，只有三个定位/搜索入口成功或充电页开始命令才将PB1拉高。两路模块有效
极性若再次变化，必须分别修改`CANNON_*_RELAY_ACTIVE_LOW`后重新构建。

## DAP虚拟串口与ESP8266

开发板v5.5原理图确认，板载DAP虚拟串口固定连接USART1；ESP8266的TX/RX引出到
右上排针，可通过跳帽连接USART3。当前调试映射如下：

| 链路 | MCU引脚 | 复用/时钟 | 配置 |
|---|---|---|---|
| DAP接收STM32数据 | PA9 / USART1_TX | AF7，APB2=84 MHz | 115200 8N1，BRR=`0x2D9` |
| DAP发送到STM32 | PA10 / USART1_RX | AF7，APB2=84 MHz | 115200 8N1 |
| STM32发送到ESP | PB10 / USART3_TX → ESP_RX | AF7，APB1=42 MHz | 115200 8N1，BRR=`0x16D` |
| ESP发送到STM32 | PB11 / USART3_RX ← ESP_TX | AF7，APB1=42 MHz | 115200 8N1 |
| 无线业务端点 | ESP8266 STA → MaixCam2 TCP服务端 | 当前开发热点 | `192.168.215.66:9000` |

USART1和USART3均使用RXNE/TXE中断，不使用DMA。DAPLink通过SWD拉低目标NRST时，
板级Q3还会复位ESP8266，因此两者同时重启，不能单独复位ESP8266。ESP8266 Boot ROM
启动日志固定为74880波特率，115200调试桥会在`ready`前显示乱码；AT固件进入正常
波特率后不再乱码。实机已确认`COM3 -> AT -> OK`双向链路以及DAP复位后的`ready`。

## MaixCAM2视觉与PMOD_TOF100

MaixCAM2使用板载相机640×480，图像原点在左上，x向右，视觉中轴以像素和图像宽度
一起通过TCP交给STM32。STM32把有效TOF视为箱体前沿距离；固定靶/自动搜索要求50～100 cm，
增加250 mm后显示靶心距离，并按`q=(37+25)/100=0.62`映射高弹道Pitch。距离定位使用人工距离
和地面0 cm弹道。自动搜索以8°/s在相对零点±50°内扫描，目标进入中心±8 px后一次锁定，
不二次回扫标定。PMOD_TOF100沿用
交付工程的接口：I2C7 SCL/SDA为A8/A9，SPI2 CS1/MISO/MOSI/SCK为B21/B19/B18/B20。
深度矩阵50×50，业务有效范围200～1500 mm，默认读取中心1×1单元。RGB与TOF尚未做
外参标定，因此目标未居中时距离可能来自背景；当前distance按键测试版忽略全部RGB目标标志，
测试时必须人工确认TOF中心点落在待测表面。

正式版本不启用MaixCAM2 UART2 B0/B1；视觉和TOF经现有`192.168.215.66:9000`无线链路
发送，避免新增未确认的STM32串口接线。当前联调版`DISPLAY_ENABLED=True`，Maix屏只显示
相机调试画面；任务触摸UI和视觉实测`DIST`显示在STM32的ILI9341上。比赛无屏运行时再将
该开关设为`False`。

## 待实机确认

1. 读取 ILI9341 `0xD3`，期望 ID `0x9341`；驱动会记录但不会因读 ID 不稳定而
   阻止显示初始化。
2. 确认 PA15 高电平点亮背光，PE4 松开为高、按下为低。
3. 测量 FSMC WR/RD 波形与数据建立保持时间。
4. 记录四角 XPT2046 原始值，核对横屏方向、交换和反向关系。
5. 快速局部刷新时观察撕裂；无 TE 条件下不承诺无撕裂动画。
6. 首次烧录自动保持版本前固定机构，逻辑分析仪确认上电Enable应答后100 Hz双轴电流帧、
   峰值编码和`ZERO CURRENT`后双轴0 A时序；Scan继续保持关闭。
7. 首次运行pitch闭环前确认正电流对应的机械方向；当前
   `PITCH_HOLD_CURRENT_POLARITY=+1`、限流0.30 A和相对角±90°保护均未实机验证；手动pitch目标
   范围±50°；TFT靶心距离75/92.5/100/125 cm的当前高弹道Pitch约为
   -68.03/-59.84/-53.35/-49.26°。
8. 断开继电器功率回路，确认初始化后PB0、PB1均为低；分别启动距离定位、固定靶和自动搜索，
   确认都只有PB1持续为高。点击发射页`BACK`应立即恢复PB1低；中途至少暂停、恢复两次，确认各段
   PB1高电平累计满30 s后才恢复低。手动或自动发射均应在PB1为低后，让PB0只输出一次约500 ms
   高脉冲，且PB0/PB1不会同时为高；单独发送`START`不得启动PB1。
9. 自动搜索首次联调保持功率回路断开并固定机构：确认yaw以约8°/s在相对零点±50°内扫动，
   目标进入中心±8 px后立即锁住且不二次回扫；遮挡目标、断开视觉、
   `ZERO CURRENT`、`DISABLE`和“立即断开发射”
   均不得产生PB0高脉冲。最后用逻辑分析仪确认PB1累计高电平满30 s后，不论当时角度、视觉、
   TOF或稳定状态如何，都先关PB1并立即出现一次约500 ms PB0高脉冲；未满30 s或暂停中不得
   击发。非暂停自动瞄准全过程应不超过120 s。
